# 1. Introducción

Consultar los datos de una empresa no siempre es suficiente para entender qué está pasando, especialmente cuando hay varios indicadores y gráficos. El Asistente IA de Purple grape permite hacer preguntas sobre la información resumida del negocio y recibir una explicación que ayude a interpretarla.

# 2. ¿Para qué sirve este apartado?

Sirve para consultar indicadores como los importes de los pedidos por mes, sus estados o las alertas de stock. Por ejemplo, se puede preguntar qué mes concentra el mayor importe de pedidos y comparar la explicación con los indicadores que muestra la propia aplicación.

También puede proponer cambios en las tarjetas del panel si el usuario activa esa opción. Básicamente ayuda a interpretar los datos y adaptar su presentación, aunque las propuestas se revisan antes de aplicarlas y el texto generado puede contener errores.

# 3. Cuestiones técnicas

El asistente se conecta desde PHP con Ollama y utiliza el modelo phi4-mini:latest. Se le envían datos agregados del negocio, evitando incluir registros individuales con información como correos, contactos o salarios. La respuesta llega en formato JSON y el servidor comprueba que las propuestas tengan una estructura permitida.

La IA no puede ejecutar SQL, modificar clientes ni emitir facturas. Los cambios del panel necesitan que el usuario pulse Aplicar y se puede deshacer el último cambio mientras se mantenga abierta esa vista. Además, la respuesta se acompaña de indicadores calculados por el ERP para poder contrastar las cifras. Para utilizar este apartado hace falta tener Ollama disponible y el modelo instalado.

# 4. Despedida, cierre y resumen

El Asistente IA añade una forma de consultar e interpretar los indicadores de Purple grape mediante preguntas. Básicamente facilita una explicación de los datos y puede ayudar a configurar el panel, manteniendo la revisión del usuario antes de guardar los cambios. Una mejora pendiente sería ampliar las comprobaciones de sus respuestas para reducir los errores de interpretación. Gracias por vuestra atención.
