# 1- Introducción
---
Purple grape es una aplicación orienntada hacia un público empresarial, está basado en un ERP (Enterprise Resource Planning) y un CRM (Customer Relationship Management).
Este publico empresarial necesita tener organizada la información de clientes, pedidos y facturas.
Cuando estos datos se llevan por separado resulta más complicado mantenerlos actualizados y seguir el estado de cada operación, por eso surge Purple Grape, para que todo esté en un mismo lugar al alcance de cada usuario.
---

# 2- ¿Para que sirve el programa?

El programa sirve para guardar y actualizar registros, emitir facturas a partir de pedidos y sincronizarlas con equipo de contabilidad. Por ejemplo: cuando un pedido está confirmado y tiene línas de productos se puede generar su factura sin volver a introducir los datos del cliente y el importe, en el caso de que ese pedido ya tenga factura devuelve la que existe, asi evitamos que se genere un duplicado.

También permite crear campos y tablas para adaptar la información a las necesidades de la empresa mostrando datos como el estado de los pediddos, importes mensuales y componentes de stock.
Básicamente permite consutar cómo va la actividad sin tener que revisar todos los registros uno a uno.

---

# 3- Cuestiones técnicas del proyecto

Purple grape es una aplicación web con interfaz hecha en HTML, CSS y JS, mientras que PHP se encarga de gestionar las peticiones y trabaja comunicándose con la base de datos SQlite, el proyecto se divide en la parte que usa el usuario, la lógica que procesa las operaciones y el almacenamiento de la información.
Esta estructura permite modificar los formularios, las tablas o los gráficos sin tener que mezclar todo el código, a su vez los datos están relacionados entre si, por ejemplo: cada pedido pertenece a un cliente y sus líneas indican los productos, cantidades y precios.

El proyecto también se conecta a un sistema contable mediante una API y permite utilizar MySQL. Además tiene una IA conectada mediante Ollama que analiza los indicadores y puede proponer cambios en el panel, aunque el usuario tiene que revisarlos antes de aplicarlos directamente.
Para controlar las operaciones se utilizan validaciones, consultar preparadas y un registro de auditoría.
Todo esto se ejecuta en un servidor con PHP y es una demostración local. Para utilizarlo en una empresa real con usuarios habría que realizar una autenticación y permisos.

---

# 4- Despedida, cierre y resumen

La aplicación permite reunir en un mismo lugar gestión de clientes, pedidos, productos, proveedores y facturas además de consultar informes y controlar stock. Báscamente busca facilitar las tareas habituales de una empresa y mantener relacionada la información para no tener que llevar cada proceso por separado.
El proyecto incluye personalización, integración contable y un asistente de IA.
Como siguiente mejora añadiría el acceso mediante usuarios y permisos para controlar que puede hacer cada persona.
