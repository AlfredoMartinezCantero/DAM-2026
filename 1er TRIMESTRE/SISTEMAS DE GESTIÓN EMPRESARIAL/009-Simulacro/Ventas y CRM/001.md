# 1- Introducción

---
En una empresa es necesario llevar un seguimiento de los clientes y de las ventas, desde que aparece una oportunidad comercial hasta que se confirma un pedido, el apartado de Ventas y CRM de Purple grape reúne esta información para facilitar la consulta que el usuario quiera ver y mantener relacionados los clientes, los productos y los pedidos.
---

# 2- ¿Para que sirve el programa?

Sirve para guardar y actualizar clientes, consultar productos y gestionar pedidos con sus líneas, por ejemplo, se puede seleccionar un cliente, crear su pedido y añadir los productos con sus cantidades y precios calculando el total automáticamente, también permite registrar oportunidades comerciales para seguir las posibles ventas que todavía no se han convertido en pedidos.

Básicamente permite consultar qué ha pedido cada cliente y en qué estado se encuentra la operación, incluye búsquedas, filtros y un calendario de pedidos para localizar la información sin tener que revisar todos los registros.

---

# 3- Cuestiones técnicas del proyecto

La interfaz utiliza formularios y tablas hechos con JavaScript que se comunican con la API de PHP para consultar y guardar los datos en SQLite.Los pedidos están relacionados con los clientes mientras que las líneas están relacionadas con el pedido y el producto correspondiente, esto permite seleccionar registros existentes y mantener conectada la información.

Los formularios y el servidor comprueban datos como las fechas, los correos y las cantidades, además, cuando un pedido ya está facturado se bloquean los cambios en el pedido y en sus líneas para conservar los datos que crearon la factura en ese momento.

---

# 4- Despedida, cierre y resumen

El apartado de Ventas y CRM permite organizar la relación con los clientes y seguir las operaciones comerciales desde una oportunidad hasta un pedido. Básicamente reúne la información necesaria para consultar las ventas y mantener sus importes actualizados. 
Como siguiente mejora, sería útil incorporar recordatorios de seguimiento para las oportunidades comerciales.
