Configurar conexión con Ollama

Necesitas un servidor Ollama accesible desde el navegador y un modelo descargado, por ejemplo ollama pull phi4-mini:latest. Abre este dashboard desde tu servidor HTTP local.

Si aparece un error de CORS, permite el origen de esta página en OLLAMA_ORIGINS y reinicia Ollama. Para arrancarlo manualmente en Linux, con el servicio anterior detenido:


    
Si Ollama funciona como servicio, configura esa variable en el servicio. En HTTPS, usa también un servidor Ollama accesible por HTTPS. Documentación de conexión.
